# Desafio SQL - Olist

Este projeto SQL foi desenvolvido utilizando a base de dados da Olist. O objetivo foi colocar em prática os conhecimentos adquiridos e auxiliar na conclusão do curso introdutório de SQL da Growdev, em parceria com a Edenred.

## Métodos utilizados no desafio

- SELECT e filtros
- JOINs
- GROUP BY e HAVING
- Subqueries
- CASE WHEN
- CTEs
- Views
- Functions
- Window Functions

## Tecnologias utilizadas

- PostgreSQL
- DBeaver
- SQL
- GitHub

## Como rodar o projeto localmente

1. Instale o PostgreSQL e o DBeaver.
2. Crie um banco de dados no PostgreSQL.
3. Importe os arquivos CSV da base de dados da Olist para o banco.
4. Abra o DBeaver e conecte-se ao banco criado.
5. Abra os arquivos `.sql` deste repositório.
6. Execute as consultas de cada bloco no DBeaver.

Os arquivos estão separados entre `bloco_A.sql` e `bloco_I.sql`, seguindo a ordem dos exercícios do desafio.
